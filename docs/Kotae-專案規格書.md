# Kotae（答え）專案規格書

每日英日面試練習 App。這份文件整理了所有已確定的規格，可以直接貼給新的 Claude 對話接著開發。

## 背景

- 使用者：台灣，目前做電子表單流程系統開發，熟悉 MSSQL，使用 Mac + VS Code。
- 目標：在日本的外商公司工程師職缺。
- 英文可以寫；日文會念但還不太會寫。

## 核心流程

1. AI 每天出新題（題數可設定 1–10 題，預設 5 題）。
2. 使用者用英文打字作答（iPad 可用 Apple Pencil「隨手寫」直接寫進輸入框）。
3. AI 回饋：文法修正（標出刪改處）、逐條中文修改說明、「面試官想聽什麼」（這題在考什麼、已講到 / 可加強、產業關鍵字）、面試優化版英文。
4. AI 把優化版翻成日文面試用語（です・ます、謙讓語，不逐字直譯），附重點句型。
5. 日文漢字全部加平假名注音（用 kuroshiro 產生 `<ruby>`，可手動修正讀音，可開關注音）。
6. 英文 / 日文都可用瀏覽器語音合成朗讀（Web Speech API，日文可調 0.8x）。
7. 複習：間隔 1、3、7、14、30 天，英文和日文分開排程。
   - 英文：重寫一次，AI 依「重點是否講到、文法、好句型」評分，不需一字不差；分數對應 忘記 / 模糊 / 記得，使用者可手動改。
   - 日文：翻卡自評（忘記 / 模糊 / 記得）。
   - 每日複習上限（預設 30，超過延到隔天，優先保留忘記與快到期的題目）。
   - 每天順序：先英文重寫、再日文翻卡，最後做新題。

## 題目分類

- 職缺：工程師 / 共通（任何面試都會問的通用題）
- 題型：自我介紹、志望動機、經驗題（STAR）、情境題、技術題、個人特質、反問題
- 主題：AI 自動標記（例：流程改善、客訴處理、團隊合作、多語溝通、學習能力、公司研究、壓力管理）

## 技術架構

- Next.js + TypeScript（網站＋API 一套），做成 PWA 讓手機 / 平板加到主畫面。
- Prisma ORM，資料庫 PostgreSQL（provider: postgresql）：上線用 Neon（Vercel 整合，免費方案），本機開發用 Docker 跑 PostgreSQL。（原定 Azure SQL，因 Azure 帳戶註冊被拒，2026-10-18 改用 PostgreSQL。）
- Claude API：出題、回饋、翻譯用 Sonnet；英文複習評分用 Haiku；開啟 prompt caching。
- 部署：GitHub + Vercel。`.env.local` 放金鑰，不上傳 GitHub。
- 登入：單一密碼登入，可記住裝置 30 天。

## 資料表

- Profile：經歷摘要、每日題數、複習上限、主題色、注音預設、朗讀速度、提醒
- Question：英文題目、中文意思、職缺、題型、主題、出題日期
- Answer：初稿、文法修正版、修改說明、面試官想聽什麼（JSON）、優化版、日文翻譯、注音 HTML、重點句型
- ReviewSchedule：題目 ID、語言（en / ja）、下次複習日、目前間隔
- ReviewLog：重寫內容、AI 分數、最終結果（忘記 / 模糊 / 記得）、日期

## 畫面（共 9 個，兩種色調各一套）

登入、首頁、作答、AI 回饋、日文版、英文複習結果、日文複習翻卡、練習紀錄、設定。另有 Logo 看板。

- 首頁：今日複習（深色卡片，優先）、今日新題進度、本週笑臉紀錄（已練習＝實心笑臉，今天未完成＝空心平嘴臉，未來＝淡色圓）。右上角設定入口。
- 底部導覽：今日 / 練習 / 複習 / 紀錄。
- 設定：主題顏色切換、我的背景、每天幾題（可用新設定重出今天的題目）、每日複習上限、注音預設、朗讀速度、每日提醒、登出。

## 視覺設計

- 中文字型：`'Microsoft JhengHei', '微軟正黑體', 'PingFang TC', 'Noto Sans TC', sans-serif`（Mac / iPad 會顯示蘋方體）
- 英文：Source Serif 4；日文：Noto Serif JP
- 色調用 CSS 變數，`data-theme` 切換：

| 用途 | 米白墨色 | 莫蘭迪藍 |
|---|---|---|
| 背景 | #F5F2EA | #EEF1F3 |
| 主色 / 文字 | #1F2328 | #3C4D5C |
| 次要文字 | #5E6470 | #5F6E7B |
| 邊框 | #E4DED2 | #D9DFE4 |
| 英文強調 | #2F45A0（淡底 #E7EAF6） | #6D8CAA（淡底 #DCE6EF） |
| 日文強調 | #B8432B（淡底 #F8E7E2） | #9A6560（淡底 #F1E4E2） |
| 模糊 / 提醒 | #6E4A0E（淡底 #F4EAD6） | #72603F（淡底 #EDE7DB） |

- Logo：圓角方形底，白色對話框裡有笑臉，右上角小圓點打勾。

## 開發階段

0. 環境準備：Node.js、PostgreSQL（Neon）、Claude API 金鑰（Console 設花費上限）、GitHub、Vercel
1. 核心：登入、出題、作答、AI 回饋、日文翻譯＋注音（約 1–2 週，完成後就開始每天使用）
2. 複習系統：排程、英文評分、日文翻卡、複習上限（約 1 週）
3. 紀錄、設定、色調切換（約 1 週）
4. 上線、PWA、細節調整
